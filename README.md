# ML-Demanda · versión de consulta

Aplicación Streamlit para proyectar la demanda de pasajeros del sistema MIO
(Metrocali, Cali). Esta copia está preparada para publicarse en Internet: solo
proyecta, no entrena.

Los modelos ya vienen entrenados y versionados en `data/models`. El entrenamiento y la
validación se hacen en el equipo del profesional; aquí llegan ya revisados.

## Archivo principal

En Streamlit Community Cloud, el *main file path* es:

```
streamlit_app.py
```
